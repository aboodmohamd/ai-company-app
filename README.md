# شركة الذكاء الاصطناعي (تطبيق أندرويد)

تطبيق بيجمع فريق ذكاء اصطناعي (مدير، مصمم، مبرمج...) بيناقش فكرة مشروعك حسب نوعها.

## التنزيل
**[تنزيل التطبيق (APK)](https://github.com/aboodmohamd/ai-company-app/releases/latest/download/ai-company.apk)**

## التثبيت (أندرويد فقط)
1. اضغط رابط التنزيل، وافتح الملف من إشعار التنزيل.
2. إذا طلب السماح، فعّل **"السماح بالتثبيت من هذا المصدر"** للمتصفح.
3. إذا ظهر تحذير Google Play Protect، اختر **"تثبيت على أي حال"**.
4. افتح التطبيق ← **الإعدادات** ← ادخل **عنوان السيرفر** و**الرمز** اللي وصلك بشكل خاص ← **اختبار الاتصال** ← **حفظ**.

> التطبيق ما بيشتغل بدون عنوان ورمز السيرفر (بيوصلوك من صاحب التطبيق).
> هالنسخة تجريبية للاستخدام الشخصي، وموقّعة بمفتاح تجريبي.
